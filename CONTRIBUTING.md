# Contributing to Solve-the-puzzle-

Thanks for your interest in contributing! This document outlines how to contribute code, documentation, and tests.

1. Fork the repository, create a feature branch from `main` or `release/v1.0.0`.
2. Implement your changes and include unit tests for core logic.
3. Run `go test ./...` where applicable.
4. Open a pull request describing your changes. Use descriptive titles and reference any related issues.
5. Follow the repository's code style and include documentation updates when adding features.

Maintainers will review PRs and request changes when needed.
